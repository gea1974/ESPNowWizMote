# ESP!Now WizMote compatible Remotes

Supported:
- Tuya 2 Button Scene Switch (modified with ESP8684-WROOM-06)
- WizMote (Wiz Smart Remote) HC165 Version
  (https://www.wizconnected.com/en-us/p/accessory-wizmote/046677603595A)
  optional: HW modification LED connected to GPIO2
- 4 Button Wifi Remote (https://github.com/sascha432/ESP8266-WiFi-Remote-Control.git, https://oshwlab.com/sascha23095123423/iot_4ch_remote)
  ESP12: with HW modification because wakeup did not work for my boards as expected
- Reset Button
  Send Button code on reset and go to deep sleep until next reset
